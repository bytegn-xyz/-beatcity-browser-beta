# BEAT//CITY // Browser Beta 0.2

> **STATUS:** CONNECTED BETA SIGNAL  
> **CREATOR + DEVELOPER:** [BYTEGN.XYZ](https://bytegn.xyz)  
> **TARGET:** Modern desktop + mobile browsers

BEAT//CITY is an original neon rhythm-game project created and developed by **BYTEGN.XYZ**. Beta 0.2 turns the original proof-of-concept screen into a small browser application with real navigation, demo-track switching, player stats, challenges, a Discover view, and a local-session chat prototype.

## // IMPORTANT CHAT NOTE

The CITY ROOM in Beta 0.2 is intentionally a **local-session/browser chat demo**. It persists on the same browser and can synchronize between open tabs on the same device. It is **not yet a public multi-user chat service**. A realtime backend plus moderation controls will be required before that feature is presented as public chat.

## // BOOT_SEQUENCE

Serve the repository root with any static web server, or publish from GitHub Pages.

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## // INPUT_MATRIX

- `A` — lane 1
- `S` — lane 2
- `K` — lane 3
- `L` — lane 4
- `Esc` — pause / exit mobile game mode
- Touch/click the four lane controls on mobile

## // BETA_0.2_PAYLOAD

- Functional Play / Discover / Challenges / Chat / Profile navigation
- Four selectable generated demo tracks
- Track-specific BPM and deterministic chart patterns
- Easy / Normal / Hard modes
- Score, combo, accuracy, energy and hype
- Browser-local player stats
- Browser-local challenge tracking
- Local-session chat prototype
- Same-browser tab chat sync
- Mobile focused gameplay mode
- Fullscreen button where supported
- No copyrighted commercial music bundled

## // NEXT SIGNAL

Beta 0.3 should connect a real backend for accounts, persistent leaderboards, public chat/presence, moderation, and an approved local-artist media pipeline.
